# Employee Directory

A simple React application created for training purposes.

## Features

- Display employee cards
- Search employees by name
- Reusable React components
- State management using useState
- Basic styling with CSS

## Technologies

- React
- JavaScript
- CSS

## Project Structure

- App.jsx: Main component and employee data
- EmployeeCard.jsx: Displays employee information
- SearchBar.jsx: Handles search input
- App.css: Project styling

## How to Run

1. Install dependencies:

```bash
npm install
npm run dev
```
